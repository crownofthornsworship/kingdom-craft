# Kingdom Craft: Light of the World

A 3D voxel survival adventure with five progressive missions, four hidden landmarks, refuge building, crafting, restoration, and mobile-friendly controls.

## Current update

- Expanded the explorable world from 23×23 to 37×37 blocks
- Added a persistent five-mission journey and discovery journal
- Added four landmarks with resource and Light rewards
- Added clearer build and crafting feedback, recipe previews, and haptics
- Improved portrait and landscape mobile controls with safe-area support
- Integrated the 1200×630 title/social artwork in-game and in link previews

A free 3D Christian voxel survival adventure. Gather resources, craft tools, build a refuge, rescue the afflicted, and wield the Sword of Truth against the shadows.

## Play

**[Play Kingdom Craft](https://crownofthornsworship.github.io/kingdom-craft/)**

## Features

- Mine and place voxel blocks in a true 3D world
- Survival and Creative modes
- Crafting, combat, health, death, and respawning
- Persistent inventory and mission progress
- Responsive keyboard, mouse, touch, and mobile controls
- A complete Lightbringer mission with a victory sequence
